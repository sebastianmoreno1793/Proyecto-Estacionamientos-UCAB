# front/vistas · «interfaz»

Componentes de React: uno por pantalla **y uno por mensaje** (como el ejemplo «Registro de Producto»
de la profesora). Solo dibujan y le avisan a su controlador; no validan ni hacen `fetch`.

| Carpeta | Pantallas y mensajes |
|---|---|
| `inicio/` | `Inicio` (sugerencia, total y estacionamientos, HU 4.2 y 7.2) |
| `mapa/` | `MaquetaCampus`, `PanelPuestos`, `TarjetaEstacionamiento` (HU 5.1 y 4.2), `Encuadre` (zoom y posición de la maqueta) |
| `reportar/` | `FormularioIncidencia` · `MensajeIncidenciaCreada` · `MensajeEstacionamientoCerrado` · `AspectoIncidencia` (HU 9.1) |
| `perfil/` | `PantallaPerfil` · `FormularioVehiculo` · `MensajeVehiculoRegistrado` (HU 2.1) |
| `cuenta/` | `FormularioCuenta` (HU 1.1) |
| `sugerencia/` | `BuscadorSugerencia` (HU 7.2) |
| `admin/` | `PantallaPuestos` + `FilaPuesto` + `MensajeCambiosGuardados` (HU 5.4) · `PantallaEdificios` + `NuevoEdificio` + `FilaEdificio` + `CamposEdificio` (HU 6.1) · `PantallaGarita` (HU 3.1, 3.2, 4.1) |
| `notificaciones/` | `Notificaciones` (HU 8.1) |
| `comunes/` | `MenuPrincipal`, `Pestanas`, `MenuAdmin`, `Iconos`, `SelectorEdificio`, `ActualizacionPWA`, `MensajeDatosNoValidos`, `MensajeHecho`, `ColoresSemaforo` (colores del semáforo, D-009), `Formato` (cifras y fechas) |
