HU 9.1 · Crear una incidencia

Autor: Moreno, Sebastian

1 Historia de Usuario2 Conversación3 Criterios de Aceptación
Como conductor de la comunidad UCAB (estudiante o profesor), quiero crear una incidencia sobre un estacionamiento para que vigilancia sepa del problema y lo atienda.

Épica: 9 · Gestión de Incidencias (R1), de la meta Seguridad del Mapa de Impacto.

Escenario de uso:

  1. El conductor abre la opción «Reportar», desde el menú o desde la tarjeta de un estacionamiento.
  2. El sistema verifica la sesión.
  3. 2.1 Si no la tiene, le muestra «Entrar».
  4. 2.2 El conductor inicia sesión con su correo institucional.
  5. El sistema muestra el formulario con los estacionamientos abiertos y los tres tipos de problema.
  6. El conductor elige el estacionamiento.
  7. El conductor elige el tipo de problema.
  8. El conductor pulsa «Enviar reporte».
  9. 6.1 Si se arrepiente, cierra el formulario y no se registra nada.
  10. El sistema valida el estacionamiento y el tipo.
  11. 7.1 Si falta alguno, le indica qué debe elegir y el conductor vuelve al paso 4.
  12. El sistema registra la incidencia con la fecha, la hora y el estado «pendiente».
  13. El sistema muestra la confirmación con el estacionamiento, el tipo, la hora y el estado.
  14. El conductor lee la confirmación.

Reglas de negocio: hay tres tipos de problema (batería descargada, conos atravesados y vehículo mal estacionado); solo se reporta sobre estacionamientos abiertos; toda incidencia nueva queda «pendiente» con su fecha y hora, y el conductor no elige el estado; solo la crea un usuario con sesión iniciada, y su correo no se muestra a los demás; si se abre desde la tarjeta de un estacionamiento, ese estacionamiento ya viene elegido.

Alcance: no incluye cambiar el estado (HU 9.2), consultar el listado (HU 9.3) ni eliminar una incidencia (HU 9.4), adjuntar fotos, escribir una descripción libre ni avisar a vigilancia con una notificación.

Dependencias: HU 1.1 · Crear cuenta con el correo institucional; HU 5.1 · Consultar los estacionamientos en el mapa del campus; HU 5.4 decide qué estacionamientos están abiertos.

Restricciones: solo el Campus Montalbán; solo navegador web, en computador y en celular; sin costos adicionales.

Diagrama de actividades: ver enlace en la descripción de la tarjeta.

1. Con sesión iniciada, si el conductor elige un estacionamiento abierto y un tipo de problema y pulsa «Enviar reporte», la incidencia queda registrada con la fecha, la hora y el estado «pendiente», y el sistema le muestra la confirmación.

2. Si intenta enviar el formulario sin elegir el estacionamiento o el tipo de problema, el sistema no registra nada y le indica qué le falta elegir.

3. Un estacionamiento que el administrador cerró no aparece en la lista del formulario y no se puede crear una incidencia sobre él.
