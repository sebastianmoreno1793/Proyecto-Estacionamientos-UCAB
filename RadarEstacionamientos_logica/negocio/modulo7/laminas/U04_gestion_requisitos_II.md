## Lámina 30 · Imagen Grande

MAPA DE HISTORIAS  
Se trata de una técnica desarrollada por Jeff Patton, muy utilizada en proyectos Scrum, que permite generar requisitos de forma colaborativa al Product Owner junto a las personas usuarias y al resto del Equipo de Desarrollo.  
Así generaremos el primer backlog de producto: Lista de Tareas priorizadas.  
Esta técnica busca obtener lo que se denomina un MVP (Minimun Viable Product o si lo castellanizamos PMV, Producto Mínimo Viable), es decir, un conjunto de funcionalidades imprescindibles (entregables) que aseguren que el producto cumpla sus funciones vitales

## Lámina 35 · Procesos Copia

CIERRE  
El detalle ultimo de el QUÉ se va a construir son los requisitos, estos pueden ser funciónales y no funcionales.  
Para llegar a ellos, bajo el enfoque clásico, se refina el Diagrama de Casos de Uso inicial, usando relaciones de Extend e Include.  
Otra opción para “desmenuzar las grandes funcionalidades” (features) de nuestro software, es hacerlo bajo el enfoque Ágil. Este enfoque exige primero que se revise colaborativamente con el equipo de desarrollo y el patrocinador, el impacto que tendrán estas funcionalidades, conocidas como épicas y /o entregables. Este impacto se registra en la Matriz de Impacto  
Y luego, se pide se desglose en Historias de Usuario (esto se conoce en SCRUM como el Backlog o lista de tareas priorizadas)

## Ventana emergente 43 · Copia Copia

Cada Caso de Uso:  
- Describe acciones que el sistema toma para producir algo de valor para el actor.
- Muestra la funcionalidad del sistema que un Actor utiliza.
- Modela un diálogo entre el sistema y los actores.
- Es un flujo de eventos completo y significativo desde la perspectiva de un Actor particular.

## Ventana emergente 44 · 

EXTEND.  
Conecta desde un Caso de Uso extendido hacia un Caso de Uso base:  
- Inserta comportamiento del Caso de Uso extendido en el Caso de Uso base.
- Se inserta sólo si la condición del extend es verdadera.
- Se inserta en el Caso de Uso base en el punto donde se nombra el Caso de Uso extend.
