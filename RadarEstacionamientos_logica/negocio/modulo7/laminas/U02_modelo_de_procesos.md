## Lámina 14 · TEXTO/IMAGEN

DevSecOps  
De qué trata?  
Es un conjunto de herramientas, prácticas y cultura que permiten que tanto el equipo de desarrollo como el de operaciones trabajen colaborativamente durante todo el ciclo de desarrollo del software.  
Busca integrar a tres equipos: desarrolladores, seguridad y operaciones  
Amerita por lo tanto de un importante cambio cultural!  
+ Info

## Lámina 16 · COMP III Copia Copia

DevSecOps  
Prácticas  
MEJORA CONTINUA (CONTINUOS FEEDBACK)  
El desarrollo de software no es una calle de un solo sentido,las organizaciones que logran el ciclo DevOps  prosperan en un ciclo continuo de retroalimentación. La retroalimentación continua no ocurre sólo al final del proceso de desarrollo del software. Requiere coordinación entre equipos durante todo el desarrollo, implementación y soporte del código, incluso en funciones que no son de TI, como el marketing. Los equipos quieren comentarios continuos para informar los próximos pasos y mejoras.  
INTEGRACIÓN CONTINUA  
Se logra contando con repositorios y herramientas que gestionen la integracion y el versionamiento. Por supuesto de manera colaborativa. En los que todo el equipo tiene acceso

## Ventana emergente 32 · 

Es el mas conocido.  
También lo llaman “cascada”  
Muy útil para:  
- proyectos pequeños.
- cuando se sabe muy bien que es lo que se quiere construir.
- cuando se domina muy bien el lenguaje con el cual se va a construir.

## Ventana emergente 33 · 

Son pequeñas cascadas.  
Se confunde con Incremental(esta es para proyectos grandes que se construyen trozo a trozo).  
Muy útil para:  
- Cuando no se tiene claro lo que se va a construir. poner en funcionamiento el software por partes.
- Cuando no se domina bien el lenguaje.
- Es la base del desarrollo ágil.
- Cada “cascadita” se puede conocer como un Sprint (SCRUM) o una historia (XP).

## Ventana emergente 34 · Copia

Grupo: es decir en un proceso siempre participa mas de una persona.  
Relacionadas: estas personas deben comunicarse, colaborar y cooperar durante la ejecución del proceso.  

## Ventana emergente 35 · Copia

Resultado: todo proceso debe generar algo. Un documento, artefacto, producto, etc.  
Cliente: Todo proceso es iniciado por alguien (cliente) quien lo invoca. Por ejemplo cuando Usted entra en un Banco para abrir una cuenta de ahorros, se inicia un proceso donde Usted es el cliente
